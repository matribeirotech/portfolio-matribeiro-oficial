import { WhatsAppStream, CRMLedger } from '@lypsyos/core';

export async function handleIncomingBooking(event: WAWebhookPayload) {
  // 1. Verifica disponibilidade real em milissegundos (Zero Double-Booking)
  const slots = await CRMLedger.getAtomicSlots({
    tenantId: event.tenantId,
    date: event.requestedDate,
    isolation: 'SERIALIZABLE_RLS'
  });

  // 2. Confirma reserva, atualiza faturamento e dispara Push PWA
  const booking = await WhatsAppStream.confirmIn1800ms(event.from, slots[0]);
  return CRMLedger.syncGoogleCalendarAndNotify(booking);
}

DECISÃO DE ENGENHARIA · ARQUITETURA NO-TOUCH

Por que removemos o driver XPT2046 e transferimos 100% do controle para o PC?

Placas ESP32-2432S028R frequentemente sofrem com leituras fantasmas (*ghost touches*) no controlador resistivo XPT2046 e desperdício de barramentos SPI. Na v3.0, a dependência de touch foi 100% erradicada do firmware embarcado, liberando RAM/CPU para gráficos a 28 FPS e transferindo o comando para um agente assíncrono em Flet (Flutter) no PC:

< 50ms Event-Driven Screen Switch

Troca instantânea entre as 7 telas da placa com 1 clique na GUI do PC via fila serial não-bloqueante.

RGB565 Live Color Engine

Seletor HEX/RGB565 no PC que repinta medidores, curvas e textos do display embarcado em tempo real.

28 FPS Ticker Tape Financeiro

Letreiro infinito da Bolsa e Cripto (USD, EUR, IBOV, S&P500, BTC, SOL, BNB) rodando suave no rodapé.

USB → SD Wallpaper Pipeline & PWM

Conversão e upload de artes JPG/PNG/BMP/GIF direto para o MicroSD via cabo USB + brilho PWM (Pino 21).
